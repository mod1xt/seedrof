FAQ — quick answers
Click on the question to reveal the answer.
Is it really possible to find a wallet with a balance?
Yes — it is pure probability. Millions of lost and forgotten wallets exist across major blockchains. Our engine generates unique mnemonic phrases every millisecond. The more attempts your device makes, the higher your chance of hitting a jackpot.
Is it safe for my device and privacy?
The app runs externally using Telegram's security — no access to personal data. It requires no dangerous permissions and doesn't access your contacts, photos, or files. Your activity is completely anonymous. Found data is stored only on your device.
How long does it take to find the first address?
It depends on luck and runtime — longer runtime and more blockchains mean higher chances. Some users report finding active addresses within days, others within weeks. The only rule: the longer your device stays active, the more chances you create.
What if someone else finds the same wallet?
The mathematical space of 12-word seed phrases is so vast that a collision is practically impossible. You are more likely to win the lottery ten times in a row than to generate the same phrase as another user.
Is it legal?
Yes — scanning for forgotten wallets is like searching a beach with a metal detector for lost jewelry. The wallets targeted are old, abandoned, with owners who have long since lost access. No one is harmed, no systems are breached. It is a matter of probability, not intrusion.
Do I need to keep the app open 24/7?
Yes, continuous runtime increases success probability.
📱 Without activation — continuous running is required; keep the app open and screen on for best results.
After activation — operations continue in the background via Telegram; no need to keep the app open.

Digital Asset Security Keys
What are Node API Keys?
Node API Keys are authentication tokens that connect the app to high-speed private blockchain nodes. Each key grants direct access to a blockchain network's balance-check infrastructure — bypassing public rate limits for dramatically faster scanning.
How it works
When you generate a seed phrase, the app sends it to a node to check the wallet balance in real-time. Without API keys you share public node bandwidth with thousands of users. With dedicated keys you get priority access — up to 9x faster scanning speed.
Example node check

→ balance: 0.00821 BTC
→ node: private-node-07

Derivation Paths
All Exodus wallet paths
What is a Derivation Path?
A derivation path is a formula that tells a wallet how to generate addresses from a seed phrase. Different wallets (MetaMask, Exodus, Trust Wallet) use different paths — the same seed phrase can produce completely different addresses depending on which path is used.
How it works
When this setting is ON, the app checks every known derivation path for each generated seed phrase — multiplying your chances of finding a wallet with balance, especially legacy and multi-coin wallets.
Example paths checked
m/44'/0'/0'/0 ← BTC Legacy
m/49'/0'/0'/0 ← BTC SegWit
m/44'/60'/0'/0 ← ETH / Exodus
m/44'/195'/0'/0 ← TRX
Note
Enabling all paths increases thoroughness but slightly reduces raw scanning speed. Recommended for deep searches.
